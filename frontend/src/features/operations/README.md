# 服务运营界面

质量守护默认展示调查与案件：先看调查数量和实际受限资源，再进入具体案件。代理网络默认展示节点清单：先看可调度候选和需要处理的节点，再调整代理池或流量路由。

## 布局与主题

界面直接继承应用的背景、文字、边框与侧边栏主题。`operations.css` 只定义以 `ops-` 开头的组件样式，不修改 `html`、`body`、`main`、侧边栏或全局按钮。弹窗通过 `OperationsDialogContent` 显式使用同一套组件样式，切换路由不会改变其他页面的控件。

顶部保留标题、状态与主要操作，说明放在相关帮助入口。指标只在需要它们的工作页展示。案件采用可搜索、可筛选、可翻页的列表，右栏显示当前限制和当前策略；详情并排比较固定出口换账号、固定账号换出口两组证据，判断依据放在独立侧栏。移动端按阅读顺序堆叠。以路由为状态的标签使用手动激活，避免鼠标按下和获得焦点重复写入历史；键盘聚焦后使用 Enter/Space 切换。

字段说明统一收在名称旁的帮助按钮，鼠标悬浮或键盘聚焦时展开；错误仍在字段附近显示。守护设置通过可深链接的四个分组组织：守护范围、响应与重试、出口恢复、归因规则。修改后的关键字段同时显示当前生效值。

代理网络只有出口节点、代理池、流量路由三个核心入口。订阅属于节点来源，在节点工具栏进入订阅管理并返回清单；`#nodes/sources` 可深链接，旧 `#sources` 仍解析到节点内的订阅管理。往返订阅管理保留节点清单的筛选与选择。

代理网络直接复用账号、模型和 API Key 页面的公共 `Button`、`TabsList`、`Table`、`Dialog`、`Input`、`Select` 和 `Label`。页面标题使用相同的字号与字重，列表使用公共工具栏和分页。`proxies/network-ui.tsx` 仅组合提示、字段及弹窗滚动结构；`network.css` 只保留表单与地址排版，不定义独立配色、导航外观或控件皮肤。信息按用途呈现：

| 维护任务 | 常驻信息 | 操作与补充信息 |
| --- | --- | --- |
| 定位出口问题 | 节点名称及订阅来源、调度状态、完整 IPv4/IPv6、检测延迟与时间、恢复方式、质量事件次数 | 搜索与状态筛选，名称进入编辑，事件次数进入 IP 历史，质量案件直接跳转；错误原因使用帮助提示 |
| 维护出口资源 | 当前节点清单和选中数量 | 直接新增、检测与订阅管理，导入收在新增菜单；选中后出现批量启停、轮换、Webhook 与删除操作 |
| 维护订阅 | 自动同步状态、上次同步结果、上次导入数、刷新间隔与下载代理 | 同步和编辑直接可达；删除确认说明已导入节点会保留并转为手动维护 |
| 组织代理池 | 可用与总成员、选择策略、回退目标与当前出口提示 | 表格列出各池；点击名称后在下方展开成员，支持搜索、批量选择、首选标记与保存/放弃；编辑、统计与删除在菜单 |
| 配置流量出口 | 默认出口、服务渠道与业务类别规则、配置解析结果 | 每条规则占一行，通过公共下拉控件选择类型和资源；继承规则按 Build / Web / Console 展示实际出口，选路计数在独立列呈现 |

节点、订阅与池使用公共居中弹窗，长表单内容独立滚动，操作保持可见；支持 Enter 提交。出口类型、池策略和回退类型使用公共 Select。节点、来源、代理池、成员与路由统一使用表格；窄屏在表格内部横向滚动，保留完整字段和操作。大批节点与成员复用 VirtualTableBody，避免同时挂载全部交互控件。

完整地址不使用重复悬浮提示。长名称仅截断时展开全文；错误、完整检测时间、图标按钮和字段帮助使用相同的提示样式；错误与字段帮助可在触屏上点开。删除操作先在界面确认。自动调度作为独立的全量兜底展示，不把入池节点从候选总量中扣除。

## 状态与统计口径

- 案件是否结案与资源是否受限分开显示。每方的处置来自案件当事方记录，不能从 investigating 推断双方仍被冻结。独立释放说明来自已提交的 `early_releases` 证据。
- 本案释放不代表资源没有其他案件限制；全局限制来自账号和出口当前状态查询。
- 近期结论分布注明案件窗口。守护命中来自本次进程计数，同一请求可能命中多个特征，不能将特征次数相加作为独立请求量。
- 节点与代理池使用统一候选条件，优先考虑质量限制、启用状态、代理配置和冷却，再考虑连通检测。动态隧道明确标识，旧 IP 的正常检测不能证明当前 IP 质量。
- 延迟中位数使用有测量值的固定出口，表示连通探测延迟。
- 路由统计是本次进程的选路计数，按实际决定选路的层级累计，包含此前配置且重启清零；自动调度不计入。目标选中表示指定节点、目标池自身成员或显式直连产出了出口；回退 / 拒绝合计池内配置回退与目标不可用导致的拒绝，现有接口不能进一步区分。两者不表示请求发送后的成功或失败。加载失败显示不可用并提供重试，不能当作零次。

## 配置交互

节点、订阅、池和池成员修改在保存后生效。检测弹窗使用独立本地草稿，关闭和取消不会修改共享网络草稿；“应用到草稿”后，路由和检测设置由网络页统一保存。保存栏在文档内保持可见，页脚不会遮挡数据。各类输入错误在字段附近显示。节点与订阅的地址读取归属当前编辑会话，关闭取消读取，迟到结果不会覆盖其他对象或手动清空的字段；保存结果只关闭其提交时的表单。池编辑结果不会关闭后来打开的表单；成员保存结果归属提交时的池，切换池后不会关闭当前成员列表。

## 验收

修改状态规则时运行 `operations-data.test.ts` 和 `quality-case-presentation.test.ts`。界面验收覆盖中英文、浅深主题、桌面与手机、数据加载失败、空列表、配置取消/草稿/放弃、案件详情，以及路由切换前后侧边栏的几何尺寸与主题颜色。完整测试记录通过案件详情按 case ID 加载，不受近期测试列表限制。
